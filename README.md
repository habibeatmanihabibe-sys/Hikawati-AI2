# حكاواتي AI

نسخة تجريبية أولى موجهة للهاتف.

## تشغيل التجربة
بعد تفعيل GitHub Pages من إعدادات المستودع:
1. افتح رابط Pages الذي يظهر في Settings → Pages.
2. جرّب كتابة قصة، وافصل المشاهد بسطر فارغ.
3. اختر صورة مستقلة لكل مشهد، ثم جرّب التكبير والتحريك والمعاينة.
4. جرّب القراءة الصوتية. الأصوات المتاحة تعتمد على الهاتف والمتصفح.

## تثبيت التطبيق
افتح رابط Pages في Chrome على Android، ثم من قائمة المتصفح اختر **Add to Home screen / إضافة إلى الشاشة الرئيسية** أو استعمل زر التثبيت إذا ظهر.

## حدود النسخة الحالية
- حفظ النصوص وإعدادات المشاهد محلياً في المتصفح؛ الصور المختارة لا تُحفظ بعد إغلاق الصفحة.
- القراءة الصوتية تستعمل أصوات النظام.
- تصدير MP4 غير متوفر بعد. لن يتم عرض زر تصدير غير عامل.
- يلزم اتصال بالإنترنت أول مرة لتحميل التطبيق؛ بعد ذلك يمكن فتح هيكل التطبيق دون اتصال، مع بقاء بعض ميزات المتصفح معتمدة على النظام.
